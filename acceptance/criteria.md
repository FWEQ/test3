# Приёмочные критерии (ATDD)

Критерии согласованы с заказчиком (владельцем продукта), тестировщиком и
разработчиком до начала реализации REST-интерфейса плеера. Каждому критерию
соответствует автоматизированный тест в `tests/acceptance/test_player_api.py`.

Тестовый плейлист: «Intro» (180 с), «Song» (200 с), «Outro» (150 с), исполнитель «Band».

| № | Сценарий | Предусловие | Действия | Ожидаемый результат |
|---|----------|-------------|----------|---------------------|
| АК-1 | Загрузка плейлиста | Плеер пуст | Пользователь загружает 3 трека | Ответ 200, в плейлисте 3 трека, текущий трек «Intro», плеер остановлен |
| АК-2 | Запуск воспроизведения | Плейлист загружен | Пользователь нажимает «Play» | Ответ 200, состояние «playing», звучит «Intro» |
| АК-3 | Пауза и продолжение | Воспроизводится «Intro» | «Pause», затем «Play» | После паузы состояние «paused»; после повторного «Play» снова «playing», трек тот же |
| АК-4 | Переключение треков | Воспроизводится «Intro» | «Next», затем «Previous» | После «Next» звучит «Song», после «Previous» — снова «Intro», воспроизведение не прерывается |
| АК-5 | Конец плейлиста | Воспроизводится «Outro» (последний) | «Next» | Плеер остановлен, текущим остаётся «Outro» |
| АК-6 | Пустой плейлист | Плейлист не загружен | «Play» | Ответ 400 с сообщением «Плейлист пуст» |
| АК-7 | Пауза без воспроизведения | Плейлист загружен, плеер остановлен | «Pause» | Ответ 409 с сообщением о недопустимой операции, состояние не меняется |
| АК-8 | Некорректный трек | Загружен корректный плейлист | Загрузка трека с длительностью 0 | Ответ 400, прежний плейлист сохраняется |
