# Спецификация на примерах: состояние плеера (SDD)

Примеры собраны совместно с заказчиком и описывают, в каком состоянии должен
оказаться плеер после последовательности действий пользователя и течения
времени. Таблица ниже — единственный источник данных для автоматизированных
тестов `tests/spec/test_playback_spec.py`: каждая строка становится тестом.

## Правила

1. `tick N` — прошло N секунд. Позиция растёт только во время воспроизведения.
2. Когда позиция достигает длительности трека, плеер переходит к следующему;
   «лишние» секунды переносятся на следующий трек.
3. После последнего трека плеер останавливается на нём с позицией 0;
   при включённом повторе продолжает с первого трека.
4. «previous» при позиции больше 3 секунд перезапускает текущий трек,
   иначе переключает на предыдущий.
5. Любое переключение трека и «stop» сбрасывают позицию в 0, пауза её сохраняет.
6. Отрицательное время недопустимо.

## Плейлисты

- **стандартный**: Intro (180 с), Song (200 с), Outro (150 с);
- **пустой**: треков нет.
